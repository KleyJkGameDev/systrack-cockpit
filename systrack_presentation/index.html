Funcionalidades

Tudo que você precisa para monitorar seu servidor

Inspirado no Cockpit, o SysTrack oferece as funcionalidades essenciais em uma interface limpa e moderna.

📊
Dashboard Unificado
Visão geral em tempo real com métricas de CPU, memória, disco, rede e uptime em um único painel. Gráficos históricos dos últimos 60 segundos.
⚙️
Monitoramento de CPU
Uso total e por núcleo, frequência atual, carga do sistema (load average 1/5/15 min) e informações detalhadas do processador.
🧠
Análise de Memória
Monitoramento de RAM e Swap com detalhes de uso, memória livre, cache e buffers. Gráfico histórico de utilização.
💾
Monitoramento de Disco
Análise de todas as partições montadas com espaço total, usado e livre. Estatísticas de I/O (leitura e escrita em MB).
🌐
Tráfego de Rede
Velocidade de download e upload em tempo real, total de bytes transferidos, pacotes e listagem de interfaces com status e IP.
📋
Gerenciamento de Processos
Listagem dos processos mais ativos com filtro por nome/PID, ordenação por CPU ou memória e opção de encerrar processos diretamente.
🔧
Status de Serviços
Verificação do status dos principais serviços systemd como SSH, Nginx, Apache, MySQL, Docker e outros.
🔔
Sistema de Alertas
Alertas automáticos para uso elevado de CPU (>70%/85%), memória (>75%/90%) e disco (>80%/90%) com indicadores visuais na interface.
🌙
Tema Claro e Escuro
Alternância entre tema claro e escuro com um clique. A preferência é salva no navegador e persiste entre as visitas.

Arquitetura

Simples, Eficiente e Totalmente Local

O SysTrack foi projetado com uma arquitetura minimalista. O backend em Python coleta métricas diretamente do kernel Linux via psutil e as transmite para o frontend usando Server-Sent Events (SSE), uma tecnologia nativa do navegador que não requer WebSockets ou polling.

O frontend é uma SPA (Single-Page Application) construída com HTML, CSS e JavaScript puro, sem nenhum framework. A biblioteca Chart.js é incluída localmente, garantindo que o sistema funcione 100% sem internet.

Instalação

Pronto em menos de 5 minutos

Instale o SysTrack como um serviço permanente no Ubuntu Server com um único script automatizado.

1
Copie os Arquivos
Transfira o diretório do SysTrack para o seu servidor Ubuntu via SCP, Git ou qualquer outro método.
2
Execute o Instalador
Rode o script install.sh com sudo. Ele instala as dependências, cria o serviço e inicia o SysTrack automaticamente.
3
Acesse o Dashboard
Abra o navegador e acesse http://SEU_IP:9090. O SysTrack inicia automaticamente com o servidor.
# 1. Navegue até o diretório do projeto cd /caminho/para/systrack # 2. Execute o instalador (requer sudo) sudo ./install.sh # 3. Acesse o dashboard no navegador # http://SEU_IP_DO_SERVIDOR:9090 # Comandos de gerenciamento do serviço: sudo systemctl status systrack # Ver status sudo systemctl restart systrack # Reiniciar sudo journalctl -u systrack -f # Ver logs
